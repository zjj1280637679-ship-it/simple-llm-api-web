# 供应商与自定义 API 格式（2026-10-29）

API卡不再显示独立协议字段。供应商预设携带协议与官方基础地址；自定义条目在菜单中以“自定义 · Gemini 格式 / OpenAI 格式 / Anthropic 格式”区分。切入新的自定义项时地址、密钥和模型ID为空，填写后由发送/拉取动作应用；未填不会发请求。

重选当前已填写的同一自定义格式不会破坏用户已填配置。兼容旧“自定义 · Gemini / 自定义 · OpenAI 兼容”名称，内部仍用api.protocol派发，不引入平行format字段。切换目标清除旧密钥与trustedTarget；改变协议清除旧原生上下文。历史设置卡不可修改当前配置，包括程序触发的供应商/模型选择。

供应商列表是输入行下方的独立浮层，支持方向键/Home/End/Enter/Escape，名称可折行。现有官方供应商保留原模型列表行为；Ark无已核实列表接口仍明示手填。

Anthropic Messages实际能力由core/stream适配提供，不能仅凭菜单声称通过。默认输出预算4096 Token，当前文本附件；无图片生成/工具调用。精确官方目标可携官方文档规定的浏览器访问header，第三方不盲加。密钥仅内存、可被当前页脚本访问，用户主动发送才传输；不额外弹重复确认。真实服务CORS/账号模型权限需要另行验证。
