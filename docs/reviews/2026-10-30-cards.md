| 问题 | 实现与依据 |
| --- | --- |
| findLast(card) 使已有后续回复的卡仍可操作 | 改为 history[-1] 关系；渲染、动作、键盘与异步 commit 共用位置判断 |

| 图表与日志需要新增整套机制 | 已提供图表/日志快照卡；未知不记作零，快照不自动变化 |
| 新人难找到如何使用 | README 44 行：一句简介、真实截图、三步开始；详细说明移至 docs/USAGE.md，docs/README.md 导航 |

| 无明确许可证 | 按仓库所有者本轮明确选择加入 MIT 与 package license 字段 |

schema 2 读取旧 schema 1 设置卡；未知卡类型/版本以数据保存并只读展示。历史原件和旧知识快照不改写。自动日志缓冲不保存；用户主动插入的日志卡是历史副本，界面已说明会随历史保存。
