## 可先执行的 Node 样本

位置：仓库根目录的命令行。宿主 [qa/text-stream-live.mjs](../qa/text-stream-live.mjs) v0.1.0 使用生产 `generateText → requestJSON → SSE`，没有另写一套供应商实现，不调用图片或 Agent 工具。

四协议分别读取 `ARK_API_KEY`、`GEMINI_API_KEY`、`OPENAI_API_KEY`、`ANTHROPIC_API_KEY`。通过自己的受信任密钥管理器或进程环境注入；不要把真实值写进命令参数、聊天或报告。模型选择账号已开通的具体 ID。以下为参数位置示例，`YOUR_ENABLED_TEXT_MODEL` 需要替换：

```sh
# 只打印计划，不读取密钥、不发网络请求
node qa/text-stream-live.mjs --protocol ark \
  --endpoint https://ark.cn-beijing.volces.com/api/v3 \
  --model YOUR_ENABLED_TEXT_MODEL

# 看清目标和资源约束后执行一次，报告路径必须尚不存在
node qa/text-stream-live.mjs --protocol ark \
  --endpoint https://ark.cn-beijing.volces.com/api/v3 \
  --model YOUR_ENABLED_TEXT_MODEL \
  --output-tokens 128 --execute --report ./output/live/ark-text-001.json
```

其他协议将 `--protocol` 与 `--endpoint` 替换为用户确认的组合；常用基础地址见 [API 设置](USAGE.md#api-设置)。脚本不把某个供应商的密钥回退用于另一个目标，不自动加载 `.env`，不跟随重定向，不自动重试。

单次固定三行提示词、一次请求、输出参数默认 128 token、最多允许 1024、60 秒超时。**输出参数和超时不等于金额封顶**；思考消耗、参数是否接受以及实际扣费仍由上游决定。截断或超时如实记录，不自动增大预算重跑。未带 `--execute` 为 `PLAN_ONLY`；`--execute` 明确表示调用当前目标可能消耗额度。

报告保存宿主版本、UTC 起止时间、运行环境、全部 `src/` 和宿主的 SHA-256、目标/模型/参数、HTTP 与允许的响应头、分片次数及前 256 次时间、正文哈希、用量和结束解释。原始密钥、正文和思考内容不输出；分享前仍检查目标名称和请求身份是否适合公开。

`SAMPLE_PASS` 仅表示该进程观察到 SSE、正文增量与最终回复一致、正常结束且固定样本匹配。只有一个正文分片时 `multipleDeltasObserved=false`，不能宣称已观察到渐进显示。`provenance.independentlyVerified=false` 明确指出报告不是独立网络鉴证；如全局 fetch 被替换，同样可能形成报告。发布验收需要复核执行环境和来源身份，不能只看状态字符串。

退出码：0 表示计划已输出或样本通过；1 表示请求已尝试但样本未通过；2 表示宿主/配置/报告写入异常。若进程被杀或报告写入中断，不可根据残留文件认定成功；`STARTED` 也不是成功。这个辅助脚本**不是产品图片 CLI 的验收**。

## 网页主路径的真实验收

Node 实网通过仍不验证浏览器 CORS 和界面。每个协议在实际部署页面分别执行：

1. 记录项目 commit、页面 URL 与 script 构建指纹、浏览器版本、日期、目标、模型、输出预算；选一个新对话，使用无私人信息的固定短提示词。登记凭据是否可用及次数/预算，报告中不放密钥。
2. 发送一次，观察回复是否逐步出现、最终文本与本次输出是否一致、是否以预期协议标记结束。记录 HTTP、请求 ID（若上游提供）、正文分片/首字/结束时间与上游用量；截图静态结果不能单独证明渐进过程。
3. 保存经人工复核的日志摘要及截图/时序记录，绑定上述源身份。未获得信息留 unknown；错误体中的配额或权限说明属于上游报告，不改写成已核实原因。

基础成功样本完成后，再在明确的额外调用预算内检查取消、续轮上下文和异常路径。没有证据的子项继续保留缺口，不要求为填写“全绿”而追加调用。

每份归档至少包含：路径、宿主、版本/提交/源码指纹、时间、输入和资源范围、观察、最低效果判定、证据文件、未覆盖项。可将审阅后的报告放入 `docs/evidence/` 并更新本表；未经实际运行，不预先创建“成功”记录。
