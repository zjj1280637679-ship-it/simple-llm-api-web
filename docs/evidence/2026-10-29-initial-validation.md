## 覆盖范围

### 普通 Ark 与现有适配器

- Gemini、OpenAI 兼容、普通 Ark 文本请求路径/认证头/参数契约；Ark 原生工具历史及 `encrypted_content` 完整回传。
- Ark Flash/Pro `images/generations`，`b64_json + png`，无虚构比例字段、组图/流式/搜索参数。
- Ark 24 个应用选项及面积/比例约束，Gemini 原 42 个选项回归；1K 应用预设与官方参考尺寸的来源区分。
- 不支持的图片模型/选项、Ark 模型列表、Agent Plan 地址在请求前明确拒绝。
- URL-only 图片返回不下载、不把 Key 发往结果 URL、不自动重试；可能已计费的边界明确。
- PNG/JPEG/WebP 签名、取消、防重复、失败、已完成图片的工具历史 checkpoint。

### 日志与安全

- 实际 fetch 边界观测；真实网络与注入的 mock 来源分别标记。
- 请求头脱敏、响应头白名单、请求/成功 JSON 响应的限量副本；HTTP 错误原始 body 不读取。
- 两页未使用 Key 的交叉回显保护、当前输入 Key 快照、已用/清除 Key 归档保护；输入过程的短前缀不永久破坏既有日志。
- 直接及大小写百分号编码密钥不泄漏；CLI 在任何目标输出前校验地址。
- 深层/宽数组、primitive、字符串、二进制、base64、循环引用和总序列化预算；固定日志 envelope 字段保持稳定。
- 日志页使用文本渲染，无模型 HTML/代码执行；导出仍包含可能私密的对话文本，不能当作已匿名数据。

### 真实网页会话命令的本地集成

- 七个 typed command 调用同一 live-page handler；UI 状态、草稿、设置、日志切页和取消通过 VM 事件级测试。
- 不返回 Key、不提供 Key/endpoint/trust setter、不允许命令参数声明授权；发送始终要求网页用户确认。
- 确认绑定准确的页面、草稿、API 配置、设置和图片参数。确认后微任务窗口的改稿/改模型/换页/取消均不发请求。
- HTTP/取消/未发送结果不会伪装成功，网页 CLI 返回非零状态并保留安全诊断。
- MCP 目标 origin/full URL 与选定 tab 校验；仅调用七个注册工具，不任意 evaluate、不开监听端口、不自动接受弹窗。

## MVP 保留边界

- 会话与日志仅内存，刷新清空；无后台保存、自动上下文压缩或文本流式。
- 图片仅文本提示词单次生成；不支持图生图/附件/批量。工具向对话返回元数据及文字，不做返回图片的模型视觉复核。
- Ark 仅使用明确的 Flash/Pro 图片能力；未知 `ep-` ID 不猜测底层模型。
- 栅格签名不是完整图片解码，浏览器解码失败会提示且不重试。
- 公共 HTTPS 语法校验不等于 DNS 反绑定防护，仍需用户信任目标服务。
- 日志为脱敏、截断的应用诊断，不是完整抓包；不承诺保留原始通信每个字节。
