# 本轮独立构件与最简宿主

这些卡片随当前 main 修订独立借用，不要求采用未合并的模块库。ID 续用候选库中尚未占用的 F-006、R-005；将来接入目录时引用同一生产实现及这些身份，避免另建重复实现。

| 构件 | 效果 | 版本与时间 / 宿主 |
| --- | --- | --- |
| F-006 原生 JSON 复制 | 保留业务键、值与分支隔离；不支持的对象显式失败 | [模块及 H-F-006 卡](native-json.json)，`npm run host:native-json` |
| R-005 供应商规则匹配 | 协议、域名、端口与路径共同匹配；相同域名不提升不同路径的证据 | [模块及 H-R-005 卡](provider-identity.json)，`npm run host:provider-identity` |

两块与两宿主分别为 0.1.0，创建/更新时间固定在卡片中。宿主只 import 对应生产块及 Node 报告支持，不加载网页、core、凭据或真实 API；标准输出包含版本、时间、观测和实际源码/宿主/卡片 SHA-256。共享报告器哈希也在报告中。修改判据或宿主实现时升宿主版本并更新卡片，不能只换模块版本。

F-006 接收有限普通 JSON、稠密数组和普通/null 原型对象。循环、accessor、非枚举/符号键、额外数组属性、非有限数字与非 JSON 值显式失败。共享对象不是循环，分支分别复制。`__proto__` 作为自有数据属性定义，输出普通对象原型不变。Proxy、并发修改和任意宿主对象不在输入契约中；总快照字节预算由持久化组合负责。该模块不检测秘密，不为任意字段赋予安全含义。

F-006 的证明责任可按输入结构归纳：原子值不变；每个对象键/数组位置递归保留；每次构造新容器；活动路径检测循环；节点/深度预算限制递归复制。预算不限制输入采集或 Reflect.ownKeys 内部分配，不能称为任意对象的全资源沙箱。这里列出证明义务和设计理由，尚未提供机器检查证明，F 保持 UNKNOWN。序列化后的字节排列、JS 的 -0/0 在 JSON 文本中的区别及原型身份不属于业务 JSON 等效承诺。

R-005 只解释本地 profile；返回 `provider` 表示所识别的域名/协议，`profileMatched` 还要求声明的路径。其有限规则表可逐项检验，URL 解析器属于信任基。该结果不能证明 TLS 之外的服务身份、目标模型支持、账号权限或真实可用性。思考模块保留旧 `verifiedModel` 字段以兼容调用者，新 `catalogMatch` 与 `evidence.liveVerified=false` 明确其局部语义。

完整 F/C/H/Q 尚未准入。宿主 local:PASS 仅覆盖表内观察；H 没有已达标替代池和编码/门槛，不填写虚构距离。保真复制与持久化、规则匹配与参数编码另有组合回归，详情见 [本轮审查](../reviews/2026-10-30.md)。
