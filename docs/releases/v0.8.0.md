# v0.8.0 · 文本、图片、视频

2026-11-15。原项目的完整新版本，保留文本与图片功能及存档兼容，新增独立视频页。

- 自建 MiniMax-H3 ref2va API 连接和本地连接文件导入。
- 图片、视频、音频参考上传；服务队列接纳、任务状态查询、指定任务取消。
- 模型未就绪时排队；预处理、推理、编码状态分别显示。
- 鉴权下载、长度/哈希验证、MP4 预览与保存。
- 任务 ID 恢复、未知提交保留、轮询与下载有界并行；不自动重复生成。
- 延续浮动导航、简洁输入框与折叠设置；不改变现有对话和图片交互。
- 构建包括全部新增模块并统一使用内容指纹缓存；Windows 验证脚本使用正确文件 URL 转路径。

配套 API 需要 CORS 支持，见[配置说明](../VIDEO_API.md)。本轮未启动 GPU；合成传输、本地浏览器观察和真实生成属于不同验证范围。最终结果见 [VALIDATION](../../VALIDATION.md)。
