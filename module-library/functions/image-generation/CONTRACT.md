# F-003 图片请求与响应提取

类型：function。效果目标：`image.request-response`。版本：0.1.0。

## 输入与输出

- 输入：图片 config、prompt、aspectRatio、imageSize，可注入 signal 与 fetchImpl。
- 输出：图片字节、供应商文字、用量及请求参数，或明确错误。

## 条件假设

- 已适配图片模型与账号生成条件
- 实际网络与返回格式符合适配器范围

## 待完整证明的保证

- 映射 Gemini 或 Ark 图片请求
- 检查栅格签名
- URL-only 响应不伪装成已下载图片

这些是需要验收的契约。局部测试只支持其中的已覆盖情形，不能据此报告全域形式证明。

## 状态、关系和副作用

请求局部状态；依赖共享日志。

调用 fetch，可能计费；不自动重试。

源码唯一来源：[src/core.js](../../../src/core.js)。入口仅封装导出边界；core.js 中的职责尚未物理拆开。独立入口不等于独立故障域。依赖闭包、测试与本文件均进入证据指纹。

## 已知限制与不保证的效果

- 只检查签名，不完整解码或测量尺寸
- 返回的比例与分辨率是请求值
- 历史真实 Ark 成功仅覆盖一次网页场景

## 最低局部实验

运行 `npm run modules:verify`，执行登记的本地用例和借用入口用例；请求构造、错误、取消、组合历史按相关测试文件验收。网络由合成 fetch 提供，外部 API 可用性不在这份通过结论内。

登记用例：[tests/core.test.js](../../../tests/core.test.js)。
