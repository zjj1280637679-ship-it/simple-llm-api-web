# F-001 图片能力与参数映射

类型：function。效果目标：`image-options.normalize`。版本、创建与更新时间以 [catalog.json](../../catalog.json) 为准。

## 输入与输出

- 输入：协议、模型 ID、可选长宽比与分辨率。
- 输出：明确的能力表、规范参数、像素预设或 IMAGE_MODEL / IMAGE_OPTIONS 错误。

## 条件假设

- 使用当前能力表列出的协议及模型
- 像素表对应供应商的有效版本需另外核验

## 待完整证明的保证

- 未知模型不继承其他模型能力
- 不将不支持的选项静默改成支持的选项
- Ark 参数转换成明确 WxH；标注应用预设与参考尺寸来源

这些是需要验收的契约。局部测试只支持其中的已覆盖情形，不能据此报告全域形式证明。

## 状态、关系和副作用

无可变会话状态；能力表冻结。

无网络、存储或收费行为。

源码唯一来源：[src/image-capabilities.js](../../../src/image-capabilities.js)。入口仅封装导出边界；core.js 中的职责尚未物理拆开。独立入口不等于独立故障域。依赖闭包、测试与本文件均进入证据指纹。

## 已知限制与不保证的效果

- 表中配置不是账号权限或生成能力证据
- 像素预设不是实际返回图片尺寸

## 最低局部实验

运行 `npm run modules:verify`，执行登记的本地用例和借用入口用例；请求构造、错误、取消、组合历史按相关测试文件验收。网络由合成 fetch 提供，外部 API 可用性不在这份通过结论内。

登记用例：[tests/image-capabilities.test.js](../../../tests/image-capabilities.test.js)。
