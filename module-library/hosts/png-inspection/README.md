# H-F-005：有界 PNG 检查的最简宿主

对应模块：F-005，目标 `png.inspect-bounded`。宿主独立版本和 UTC 创建/更新时间见 [宿主目录](../catalog.json)。

```sh
npm run modules:host -- F-005
# 或直接运行
node module-library/hosts/png-inspection/run.mjs
```

条件：Node.js 20+ 与模块源码。默认 `local` 模式，不接受 `--live`，不需要生产页面、供应商、API 密钥或可写输出目录。宿主直接导入 F-005，仅供应一个内联已知 1×1 RGBA PNG、CRC 单字节损坏反例和一个不足字节上限。

成功判据：返回宽高均为 1、解压字节数为 5；CRC 损坏和字节超限明确失败；调用后原字节不变。输出 JSON 报告实际观察、模块/宿主修订及运行时间，失败退出码为 1。

最简性：一份有效样本与两个有区分力的反例就能观察本宿主目标，无需完整 Gemini/Ark 模拟器或 PNG 生成器。这是工程上的小宿主，不声称全局最小；更多边界由登记测试覆盖。

结论仅限结构检查的局部效果，不代表 PNG 全规范合规、图像内容质量、模型生成能力或 F/C/H/Q 完整准入。更改宿主样本、观察或判据后须重新记录版本/时间与证据。
