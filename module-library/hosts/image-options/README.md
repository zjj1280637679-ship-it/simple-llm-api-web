# H-F-001：image-options.normalize 的最简宿主

对应模块：F-001@0.1.0。宿主版本、创建与更新时间以 [宿主目录](../catalog.json) 为准。

在仓库根目录运行：

```sh
npm run modules:host -- F-001
```

也可直接运行 `node module-library/hosts/image-options/run.mjs`，不依赖完整网页或测试套件。输出 JSON 包含模块与宿主修订、模式、验证时间、观察结果和限制；失败退出码为 1。

## 这个宿主提供什么

- 协议/模型/选项输入
- 结果观察与异常检查

最简性依据：不需要网页、密钥、服务或文件；只保留输入、函数执行及结果判据。 这是当前契约下的工程边界，不宣称全局最小。

## 环境与验收

- Node.js 20+ 与仓库源码
- 当前图片能力表

成功判据：

- 默认 Ark 选项映射为 2048x2048
- 未知模型及不支持尺寸被明确拒绝

默认模式为 `local`。该目标在本机即可实际执行，不需要外部 API；不接受 `--live`。

## 结论边界

- 仅验证参数映射，不证明账户或模型生成能力

宿主通过只支持以上判据；不自动使 F/C/H/Q 通过。测试宿主、夹具、观测或判据改变后，需要更新宿主时间与必要版本并重新验证。
