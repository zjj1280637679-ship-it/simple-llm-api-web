# H-R-002：page-command.route 的最简宿主

对应模块：R-002@0.1.0。宿主版本、创建与更新时间以 [宿主目录](../catalog.json) 为准。

在仓库根目录运行：

```sh
npm run modules:host -- R-002
```

也可直接运行 `node module-library/hosts/page-session/run.mjs`，不依赖完整网页或测试套件。输出 JSON 包含模块与宿主修订、模式、验证时间、观察结果和限制；失败退出码为 1。

## 这个宿主提供什么

- 内存页面状态
- 少量真实状态处理器
- 拒绝发送的确认处理器

最简性依据：不用完整网页，用最小状态和处理器使间接效果可观察。 这是当前契约下的工程边界，不宣称全局最小。

## 环境与验收

- Node.js 20+ 与仓库源码

成功判据：

- 设置草稿与导航后可读取同一状态
- 拒绝发送不触发 send 处理器

默认模式为 `local`。该目标在本机即可实际执行，不需要外部 API；不接受 `--live`。

## 结论边界

- 验证命令到处理器的关系，不是 DOM、浏览器或 MCP 连接验收

宿主通过只支持以上判据；不自动使 F/C/H/Q 通过。测试宿主、夹具、观测或判据改变后，需要更新宿主时间与必要版本并重新验证。
