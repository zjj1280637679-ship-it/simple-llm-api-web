# H-C-001：conversation.image-turn 的最简宿主

对应模块：C-001@0.1.0。宿主版本、创建与更新时间以 [宿主目录](../catalog.json) 为准。

在仓库根目录运行：

```sh
npm run modules:host -- C-001
```

也可直接运行 `node module-library/hosts/agent-image-turn/run.mjs`，不依赖完整网页或测试套件。输出 JSON 包含模块与宿主修订、模式、验证时间、观察结果和限制；失败退出码为 1。

## 这个宿主提供什么

- 单轮消息与文本/图片配置
- 确认、历史、结果回调
- 受控工具往返或真实 API

最简性依据：去掉聊天 UI，保留实现组合效果必须的工具往返、回调和结果交付。 这是当前契约下的工程边界，不宣称全局最小。

## 环境与验收

- Node.js 20+ 与可写目录
- 真实模式需要 Ark 文本工具能力和图片生成条件

成功判据：

- 工具调用产生一份图片结果
- 工具历史被保存
- 后续文本回复非空

默认模式为 `synthetic`。真实模式使用 `--live`，需要从环境提供 `ARK_API_KEY`；详细设置见 [总说明](../README.md)。本次只运行默认模式。

## 结论边界

- 合成模式的工具调用由夹具提供
- 真实模式文本模型未调用图片工具时本次目标失败，不伪装成功
- 宿主仅批准首次图片调用；不证明所有轮次或计费恰好一次
- 不验收图片内容或尺寸

宿主通过只支持以上判据；不自动使 F/C/H/Q 通过。测试宿主、夹具、观测或判据改变后，需要更新宿主时间与必要版本并重新验证。
