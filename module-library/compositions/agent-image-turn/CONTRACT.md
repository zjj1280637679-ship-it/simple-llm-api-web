# C-001 对话 Agent 调图片并继续对话

类型：composition。效果目标：`conversation.image-turn`。版本：0.1.0。

## 输入与输出

- 输入：文本与图片 config、历史、设置、确认/结果/历史回调。
- 输出：对话文本、原生历史、图片工具结果；失败附可恢复历史。

## 条件假设

- 文本模型支持所声明工具
- 图片路径可用且回调契约成立
- 任务范围在当前轮次和次数边界内

## 待完整证明的保证

- 工具调用经图片命令分发
- 同一轮相同调用去重
- 工具完成后保留原生上下文，后续文本失败不自动重做图片

这些是需要验收的契约。局部测试只支持其中的已覆盖情形，不能据此报告全域形式证明。

## 状态、关系和副作用

每次调用独立 history/completed/pending；共享日志及外部回调状态须另外建模。

多次网络请求、确认回调、历史与结果回调。

源码唯一来源：[src/agent.js](../../../src/agent.js)。入口仅封装导出边界；core.js 中的职责尚未物理拆开。独立入口不等于独立故障域。依赖闭包、测试与本文件均进入证据指纹。

## 已知限制与不保证的效果

- 图片配置会使普通文本请求携带工具声明
- 工具结果 ok 不包含完整图片解码或内容验收
- 去重不跨轮；不保证服务端账单恰好一次
- 组合真实 API 闭环尚未验收

## 最低局部实验

运行 `npm run modules:verify`，执行登记的本地用例和借用入口用例；请求构造、错误、取消、组合历史按相关测试文件验收。网络由合成 fetch 提供，外部 API 可用性不在这份通过结论内。

登记用例：[tests/agent.test.js](../../../tests/agent.test.js)。
