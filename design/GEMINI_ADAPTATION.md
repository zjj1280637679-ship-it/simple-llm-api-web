# Gemini 自适应设置的理想效果模型

模型 0.1.0；2026-11-04（北京时间）；开发态 0.6.0。阶段目标仍为少量操作使用 AI，同时使专家参数可达。此模型只覆盖当前 generateContent 文本请求、设置卡及 models 元数据；Live、音频生成、Interactions、搜索 grounding、缓存资源管理、结构化输出等仍各有独立实现义务。

## 对象、条件与效果

令 C=(端点、协议、模型、当前会话的模型回执)，P 为用户保留的参数偏好，H 为卡片历史，E 为有日期/范围的能力证据。密钥只授权访问已配置目标；密钥字符形状不证明供应商、模型能力、余额、地区权限或额度。

能力解释 `A(C,E,f) ∈ {SUPPORTED, UNSUPPORTED, UNKNOWN}`。本轮的 UNSUPPORTED 同时包含明确不接受和明确不生效，两者的原因保留在来源文档；它不等于用户无权尝试其他途径。模型列表的方法声明仅判断是否适合本工作台的方法，不能推出当前账号有生成配额。

`UI = Project(C,P,H,A)`；`Request = Encode(C,Effective(P,A))`。

| 义务 | 理想指标 / 可检查谓词 |
| --- | --- |
| 明确无效控制收缩 | `A(f)=UNSUPPORTED ⇒ f∉Editable(UI) ∧ f∉Request`；已知无效控件暴露数、请求残留数均为 0 |
| 未知保持未知 | `A(f)=UNKNOWN ⇏ UNSUPPORTED`；未知模型和滚动别名仍可手填、进入深层格式选择；不宣称已经验证 |
| Gemini 专属控制可达 | 使用 Gemini 格式时，已接入参数的设置值能到达正确的 generateContent 字段；已选择参数丢失数为 0 |
| 默认保真 | 未明确选择的新增参数不发送；`0`、`false` 与留空分别表示，默认新增字段数为 0 |
| 协议隔离 | 非 Gemini 请求不携带 Gemini 专属字段；仅输入密钥不改写协议、端点或模型 |
| 偏好与生效分离 | 收起不清空采样偏好；返回适用模型后恢复可编辑。发送时移除已明确无效的值，连无效旧值的数值校验也不阻断新模型 |
| 证据归属 | models 回执绑定端点+模型，只在当前密钥会话内使用；改变密钥/地址/协议即撤销回执和旧列表；刷新不伪装成新请求验证 |
| 格式知识独立 | `thinking=true` 不推出 `thinkingLevel` 或 `thinkingBudget`；没有具名格式记录且未明确不支持时，深层手选格式可达 |
| 工作区交接 | `请求配置所属工作区 = 动作目标工作区 = 回执写入工作区`；切换可见页面不改变该等式 |
| 历史独立 | `Live(c,H) ⇔ c=last(H)`；冻结卡保存当时模型、能力解释和参数；新配置不改写旧记录 |
| 无额外调用 | 输入、渲染与参数选择不自动发生成请求；模型列表只在明确点击时请求，无自动重试或扩大额度 |

收益分别观察：常用界面选项减少、专属功能表达增加、解释成本降低。损失分别观察：有效参数误隐藏、未知被判死、无效字段残留、偏好丢失、额外网络调用；不以一个总分互相抵消。操作距离采用点击/展开次数，不称为未经编码的汉明距离。

## 当前策略与分工

| 模块 | 输入 → 输出 | 自有状态 |
| --- | --- | --- |
| gemini-capabilities / F-021 | 协议、具名模型、端点绑定回执 → 三值能力、方法分组 | 无；有限具名表及经白名单提取的回执 |
| gemini-request / F-022 | 能力+显式偏好 → 生效参数、生成配置 | 无；不执行请求 |
| gemini-settings-markup / F-023 | 能力+偏好 → 转义后的深层表单/历史行 | 无；不捕获凭据 |
| reasoning | 可用模板 → 家族/等级/预算选择 | 无；Gemini 模型规则由 F-021 统一拥有 |
| workbench / core | 用户事件、选择、请求 → DOM/网络效果 | 沿用工作区与 dispatcher；新增参数不增加卡片生命周期 |
| card-types / persistence | 已记录数据 → 历史和备份 | 保存偏好及解释快照，当前回执不进入 API 存档 |

已登记的 3.6/3.7/3.8 Flash、4 Argon 按文档收起温度、Top P、Top K；不外推所有未来名称。2.5 Pro/Flash/Flash-Lite 保留各自预算范围，3.x 使用对应等级。未知别名保持手动入口。models 返回 thinking=false 时收起思考；topK 缺失时按 Model 文档收起 Top K。未声明 generateContent 的模型收至“其他方法模型”，未知方法保留候选。

新增深层控制：公开思考摘要 includeThoughts、输入媒体精度 mediaResolution、seed、stopSequences，以及条件式 topK。思考摘要请求与思考强度分开，合并 thinkingConfig 时二者不覆盖；摘要缺失仍可得到正常正文。没有声称 seed 保证逐字复现。图像生成参数仍由图片工作台管理；本轮不把文本控制冒充图像、Live 或 Interactions 参数。

## 验证边界与扩展

有限模型枚举端点种类×模型代表×thinking 回执×摘要选择×种子选择，直接调用生产函数。组合回归检查设置卡、冻结动作、模型列表分组、凭据切换撤销、备份保真及请求字段。浏览器验收另看真实布局和点击；没有真实密钥时不能声称账号权限、计费、限额或上游运行成功。

新增能力先声明作用接口、模型证据、条件和未知解释，再接入独立请求投影及最简宿主。接口错误保留原有诊断路径；本轮不从任意 400/403/429 自动学习永久禁用规则，以免把参数错误、权限不足与临时限额混为一谈。

来源、时效与局限见 [Gemini 适配说明](../docs/GEMINI_ADAPTATION.md)。

## 0.6.2 交接反例

Model 回执仅确认 thinking=true 时，原实现收起了未知格式入口并忽略手选预算；现按“是否有具名格式记录”判断入口。另修复显式指定图片工作区拉取模型时读取可见聊天配置的问题，目标工作区贯穿请求、忙碌状态和能力回执。

验收指标分开记录：已知无效选项暴露数=0、已知无效字段残留数=0、已接入显式参数丢失数=0、未知格式入口误隐藏数=0、回执跨工作区写入数=0。数值目标限定于本模型列出的场景；有限枚举与回归结果作为局部证据，不推出未知模型或真实账号全部可用。
