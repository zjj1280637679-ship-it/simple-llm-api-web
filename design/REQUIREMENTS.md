# 产品设计要求

## 2026-10-28：对话 Agent 调用图片工作台

### 已确认的用户目标

用户原话：
> 好的再在设计稿记一下第一页的agent要可以用内置ci l调用第二页的图片工作台

- 按当前上下文，将「ci l」理解为 **CLI**。
- 第一页（文本对话页）的 Agent 应能通过**内置 CLI** 调用第二页的**图片工作台**。
- 本次仅记录设计要求，不实施真实 API 调用、命令执行或新功能界面。

### 设计建议（合理延伸，非用户额外确认的要求）

- 两个入口复用同一套图片能力、参数定义与结果结构，避免对话工具与图片工作台行为分叉。
- 图片调用结果应可返回并供对话 Agent 后续使用。
- 将 CLI 设计为可独立调用的工具入口，不锁定为某个固定工作流。

### 当前边界

- 现有 HTML 仍保持纯本地交互，不连接真实服务、不执行真实 CLI 命令。
- 不改变已有界面，不添加面向用户的设计说明文案。
- 此要求同时以不渲染的 HTML 注释保存，确保单 HTML 流转时仍携带该要求。
