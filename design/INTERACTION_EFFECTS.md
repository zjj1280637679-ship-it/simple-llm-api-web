# 交互理想效果模型

模型版本 0.1.0；建立于 2026-11-04（北京时间）。对应开发态 v0.5.1。目标、条件、策略与验证证据分别记录；这里的谓词是验收义务，不表示全部实现已被形式证明。

## 场景与效果

本阶段需求/条件方向保持不变：静态浏览器工作台、有限会话集合、基础操作浅层可达、历史业务记录不可改写。范围包含会话搜索、设置历史卡与已登记图片预设；供应商结果、全部浏览器和输入法实现不在本模型的有限证明内。

设 H 为单工作区有序历史，c 为其中一张卡，S 为当前配置，V(c) 为卡的已捕获值。卡的业务活跃关系为：

`Live(c,H) ⇔ last(H) = c`。

动作接纳仍为 `Live ∧ 已登记动作 ∧ 参数条件 ∧ 宿主条件`；异步提交另核对对象身份与历史位置。读取历史不产生业务修改。无需保存 active / expired / pending 卡片生命周期状态。

| 效果义务 | 形式表达 | 最低可观察指标 | 当前策略 |
| --- | --- | --- | --- |
| 搜索输入连续 | `PatchResults(H,q)` 后，输入节点身份、值、选择区间、焦点及输入法组合会话保持不变 | 顺序输入 ab 得 ab；中间插入/删除正确；组合输入过程中不重建输入框 | 输入事件只替换结果容器；同值事件幂等；组合结束后提交查询 |
| 历史解释独立 | 固定渲染版本和工作区类别时，`¬Live ⇒ Render(c,S1)=Render(c,S2)` | 切换当前协议、参数后，旧卡参数与协议说明逐字相同 | 捕获最小 displayContext.protocol；历史渲染只使用快照 |
| 缺失信息保真 | `protocol ∉ V(c) ⇒ historicalProtocol=UNKNOWN` | 旧备份提示“历史协议未记录”，不填入当前协议 | 兼容新增可选快照字段；旧档保留未知 |
| 冻结仍可读 | `¬Live ⇒ Edit=0 ∧ ReadRecordedValues=1` | 刷新/切页后仍直接可见已记录参数；历史动作效果数为 0 | 模型旧卡投影为静态摘要；不依赖折叠状态；取消整卡透明度与全子树指针禁用 |
| 渐进选择可达 | 对已登记集合 R×Z，任意 `(r,z)` 均可由比例选择和分辨率选择到达 | 浅层常用比例不多于 3 个；不丢失任何已登记组合；切换一维保留另一维 | 常用比例、分辨率分组；其余比例置于更多比例 |

低操作距离按完成任务的操作数评估，只有显式二进制编码的配置差异才称汉明距离。减少浅层选项是当前场景的注意力策略，不是所有场景的普遍最优。罕见比例增加一次展开操作，是本次接受的取舍。

奖励与惩罚分别观察：易发现、易读、常用路径短属于奖励；输入破坏、历史漂移、记录不可读属于惩罚。二者不折成一个抵消分数；本次三个缺陷对应的最低指标必须分别达成。

## 分工与组合

| 实现身份 | 拥有的分工 | 交付关系 |
| --- | --- | --- |
| history-markup | 会话列表的纯文本/HTML投影 | 接收过滤后的条目；不控制输入框生命周期 |
| workbench | DOM事件、查询值、局部结果写入、页面组合 | 搜索结果更新不触碰编辑节点；业务卡动作仍走 dispatcher |
| card-types | 捕获和持久化历史所需数据 | 仅捕获协议标识作为解释条件；不捕获密钥 |
| settings-markup | 当前编辑视图及历史静态视图 | 历史分支不从当前配置补全解释 |
| card-markup / interaction-cards | 外壳禁用与业务动作接纳 | 禁用业务效果、保留记录阅读；两者独立验收 |
| image-options-markup | 图片参数可见层级和纯选择转移 | 原样使用能力表；不声明供应商实测可用性 |

兼容性：model 卡 version 1 增加可选 displayContext；已有字段与读取方式兼容。模块/宿主版本单独提升。缺此字段的历史卡不追溯推断协议；恢复后仍在末项的活卡按当前配置工作，离开末项时捕获其当时上下文。

## 验证与未完成义务

生产导入的最简宿主、组合回归、有限模型和线上浏览器观察分别提供证据。有限模型枚举当前协议分类、若干参数代表值及已登记图片组合；不穷举无限字符串、DOM、IME、供应商状态或全部调度。

历史解释独立性可从纯历史分支的数据依赖得到局部论证；搜索连续性仍依赖浏览器保持未替换输入节点的编辑行为，须用真实浏览器反例验证。静态摘要保证记录字段不藏在 details 中，不保证每位用户的视觉可读体验。当前运行构建仅投影本版本开发态；构建版本之间没有独立的语义连续性保证。

执行与部署证据见 [本轮记录](../docs/reviews/2026-11-04-interaction-effects.md)，有限模型边界见 [models](../development/models/README.md)。
