# 图片页理想效果模型

版本 0.7.0；2026-11-04。继承 Gemini 文本适配的条件—策略—指标关系，作用域为当前图片页的单次文本生成图片。密钥只提供鉴权；不能从密钥外形推断模型、能力、权限或余额。

需求：用户只面对当前目标可操作的图片参数，能使用已接入的模型专属控制，切换连接和模型不破坏偏好与历史解释。

条件 C =（协议、精确模型身份、带日期的能力资料、宿主已实现入口）。端点是否兼容、账号权限、配额、生成效果另由实际请求观察。未知模型不继承邻近名字的规则；“当前应用尚未适配”与“供应商不支持”分别表述。

用户偏好 P、有效选择 E、界面 V、请求 W、历史 H 各有身份：

- E = project(C, P)：比例和分辨率不适用时暂用该模型默认，兼容时恢复；只改变一个轴不重置另一轴。用户重新选择只覆盖对应偏好。
- V = render(C, E, P)：常用比例浅层可达；更多比例可展开；固定分辨率不展示其他分辨率；思考等级按模型枚举。暂未生效的偏好可读。
- W = serialize(C, E, P)：只写适用参数；不把隐藏的思考等级、文本采样、JSON 或工具配置送入图片请求。2.5 图片模型不发 imageSize。默认不附加 thinkingConfig。
- H(t) = capture(C(t), E(t), P(t))：冻结模型卡保存当时有效参数；未来切换和刷新不得重新解释 H(t)。旧存档缺项显示“未记录”。

| 效果指标 | 理想目标 | 本地判据 |
| --- | --- | --- |
| 不可用选项暴露 | 已知不适用选项为 0 | 各模型的比例、分辨率、思考等级与具名表相等 |
| 独有控制覆盖 | 已登记且接入的图片参数均可操作 | 返回内容、支持的思考等级、模型特有分辨率逐一可达 |
| 界面—请求一致 | 适用字段映射一致，隐藏字段泄漏为 0 | 检查生产命令到合成 HTTP 请求体 |
| 偏好保真 | 兼容模型切回时恢复 | 宽→窄→宽；中途修改一个轴 |
| 历史稳定 | 冻结后解释变化为 0 | 切模型、保存、恢复后的静态标记完全相同 |
| 能力诚实 | 未知不升级为支持或账号授权 | 未收录模型不发生成请求；不声称真实密钥已验收 |

本期策略：统一具名能力表驱动比例菜单、模型设置、请求投影和 image_generate 工具 schema。对话调用图片工作台也使用图片页的专属偏好；工具只能给提示词、比例和分辨率，不能替换连接或密钥。

范围外的效果：参考图编辑、搜索 grounding、输出编码控制、Interactions API、多轮图片上下文和精确张数控制尚未接入。本轮不因为某供应商支持这些能力就展示未实现按钮。原始尺寸的成功解码、文件交付、持久化、画面符合提示词分别验收。

有限穷举覆盖登记域，不构成任意 DOM、所有 API 变更或完整 F/C/H/Q 证明。阶段目标未改变，当前是原目标在图片条件下的投影扩展。
