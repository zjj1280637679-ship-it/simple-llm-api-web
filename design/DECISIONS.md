# 当前策略及其适用范围

版本 0.4.0；2026-10-30（北京时间）。这些记录解释当前实现，不把策略提升为所有后续宿主的永久规则。必要条件、兼容范围与可选策略分别审查；更换策略后重验受影响效果。

| ID / 目标 | 当前条件与策略 | 代价、替代途径、复核触发 |
| --- | --- | --- |
| D-01 凭据只到达授权目标 | 公共静态 BYOK 网页；公开 HTTPS 域名、目标绑定、不自动跟随重定向 | 暂不接本机/IP 模型。局部模型宿主可另行声明网络/CSP/授权策略；不能推断本机模型应被产品永久禁止 |
| D-02 保留诊断而不回显凭据 | HTTP 错误读取上限 8 KiB/1.2 秒，投影明确字段并脱敏；状态、上游说明与推断分别表示 | 超限、非 JSON 或超时诊断可能缺失；可按特定供应商增加有证据的适配。现有凭据反例继续通过 |
| D-03 保留参数控制意图 | 默认省略思考字段；精确本地规则匹配或手选模板，范围外组合暂不接纳 | 当前公共子集小于上游全部能力；需要目标模型/API 版本证据后扩展，不能说“模型不支持”。Anthropic Top P 省略是当前范围，非所有版本禁令 |
| D-04 防重复消耗 | 单次网络失败不自动重试；图片调用走当前确认回调和调用快照 | 不表示自动重试或批量授权永远不合理；候选应定义授权范围、幂等性、预算、失败分类与取消关系，再单独验收 |
| D-05 保存保真且排除凭据 | API/card 显式投影；native raw 按普通 JSON 复制；已提交凭据碰撞则不写新快照 | 字段名不等于秘密；不能通过删 native 字段取得保存成功。未知、从未登记的用户文本秘密无法自动识别；备份仍含私人内容 |
| D-06 界面简洁且操作可达 | 悬浮组按实测几何切换正常流，当前使用 1/3、0.65 等策略阈值 | 阈值是候选启发，不是已证明最优点；物理 Safari/软键盘、放大和长内容实测可促使换策略 |
| D-07 有限资源与可终止 | 附件 5/8 MiB、快照 48 MiB、原生复制深度 64/节点 100000、请求等待 30 分钟 | 这些是当前实现预算，超限表示此路线未覆盖；可设计分块、外部存储、流式变换等候选，不能等同目标无解 |
| D-08 已完成的证据 | 完成状态、内容语法、图片候选文件、解码/交付、用户满意分别表示 | 缺少 finish 元数据的兼容 JSON 入口暂可返回结果但 completion=unknown；严格宿主可要求 complete。STOP 也不证明业务目标达成 |

审查一条新限制时，记录目标、触发条件、现有证据、收益/代价、替代路线和复核触发。无法提供这些信息时标为待论证策略，不使用“安全”“最佳实践”“已证明”填补理由。

对本地结构能执行的检查包括版本/时间、路径存在、声明依赖与宿主输出指纹。语境、适用范围、形式证明及效果充分性仍需实质审查；CI 通过不替代它们。不存在“禁止使用禁止一词”的规则。


D-08 的解释层与接纳层现分别位于 completion-evidence 和 completion-policy；未知未来标记与明确截断都可能暂不接纳，但理由分别保存。当前 JSON 兼容与 SSE 严格 framing 的差异是策略，不篡改观察。

## D09：以历史末项定义交互卡活跃性

目标是极简交互与减少重复状态。活跃性由工作区最后一项推导，任何后续历史都冻结旧卡；参数和业务快照保留。动作统一经过 dispatcher 与类型登记表，异步写回再次确认位置。确认等待只保留临时 Promise 资源，刷新不恢复调用。图表/日志采用主动快照，不让冻结历史随外部状态变化。备份面板和普通结果展示仍有独立界面，继续迁移需明确对应目标而非追求卡片数量。详细条件及验证见 [协议](../docs/INTERACTION_CARDS.md)。
